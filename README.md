## 📘 1. Loan Default Project Overview

Loan_default aims to build a full pipeline for predicting whether a loan will default or not. The project includes:

- Build an end-to-end machine learning workflow

- Clean and prepare data for modeling

- Train a model to predict loan default

- Automate the whole pipeline using Airflow inside a VM

- Produce outputs such as:

- cleaned dataset

- train/test split

- trained model file

- evaluation metrics

- predictions

## Features

- Data processing pipeline (raw → processed)  
- Configurable machine-learning model training  
- Separation between data ingestion, processing, modeling for clarity & modularity  
- Automation via DAGs (for scheduling / reproducibility)

## 💻 3. How to Run the Project (Inside VM)
**Step 1 — Connect to VM**
```
ssh username@<VM-IP>
```

**Step 2 — Clone Repo**
```
git clone https://github.com/sirawatK/Loan_default.git
cd Loan_default
git checkout dev
```

**Step 3 — Install Packages**
```
pip install -r requirements.txt
```

**Step 4 — Start Airflow (inside VM)**
```
docker-compose up -d
```

**Step 5 — Open Airflow UI **

Open your browser →
```
http://<VM-IP>:8080
```


Login:
```
username: admin
password: admin
```

**Step 6 — Run the DAG**

Run loan_default_dag once.

Airflow will automatically:

Load raw dataset

Clean & preprocess

Create train/test split

Train machine-learning model

Save results inside artifacts/

## 🧪 6. How the Model Works

Load datas

Clean missing values

Encode categorical variables

Scale numeric features

Train model (Logistic Regression ,XGBoost or Random Forest)

Evaluate using:

- Accuracy

- F1-score

- ROC-AUC

- Save model for prediction

This gives a reliable way to estimate whether a loan will default.
